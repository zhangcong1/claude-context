# GraphRAG 测试项目

## 项目概述
这是一个用于测试GraphRAG知识图谱插件的示例项目。

## 主要功能

### 用户管理
- 用户注册和登录
- 用户信息管理
- 权限控制

### 组件系统
- 可复用的UI组件
- 组件状态管理
- 事件处理

## 技术栈
- TypeScript
- React
- Node.js
- PostgreSQL

## 安装和运行
```bash
npm install
npm run dev
```
