# 🧪 GraphRAG插件测试指南

## 📋 测试环境准备

### 1. 安装依赖
```bash
cd vscode-graphrag
npm install
```

### 2. 编译插件
```bash
npm run compile
```

### 3. 验证编译结果
确保 `dist/` 目录包含以下文件：
- `extension.js`
- `graph.js`
- `parser.js`
- `webview/graphViewer.js`

## 🚀 VS Code插件测试

### 1. 启动VS Code
```bash
code .
```

### 2. 安装插件
1. 按 `F5` 启动调试模式
2. 选择 "Extension Development Host"
3. 等待新的VS Code窗口打开

### 3. 测试命令

#### 构建知识图谱
1. 按 `Ctrl+Shift+P` (Windows/Linux) 或 `Cmd+Shift+P` (Mac)
2. 输入 "GraphRAG: 构建知识图谱"
3. 点击执行

**预期结果：**
- ✅ 显示进度条
- ✅ 解析项目文件
- ✅ 显示构建完成消息
- ✅ 状态栏显示节点和边数量

#### 查看知识图谱
1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 "GraphRAG: 查看知识图谱"
3. 点击执行

**预期结果：**
- ✅ 打开Webview面板
- ✅ 显示交互式图形
- ✅ 支持节点点击跳转
- ✅ 支持搜索和过滤

#### 其他命令测试
- `GraphRAG: 导出知识图谱` - 导出JSON文件
- `GraphRAG: 导入知识图谱` - 导入JSON文件
- `GraphRAG: 清空知识图谱` - 清空图谱数据

## 🐛 常见问题排查

### 编译错误
```bash
# 清理并重新编译
rm -rf dist/
npm run compile
```

### 插件无法激活
1. 检查 `package.json` 配置
2. 确认 `main` 字段指向正确
3. 查看VS Code开发者控制台错误

### 解析失败
1. 检查文件编码（应为UTF-8）
2. 确认TypeScript版本兼容性
3. 查看控制台错误日志

### 可视化问题
1. 确认D3.js正确加载
2. 检查Webview权限设置
3. 验证数据格式正确
