## 📋 功能概览

### ✅ 已实现的核心功能

1. **多语言代码解析**
   - TypeScript/JavaScript 文件解析
   - Vue 单文件组件解析
   - JSON、Markdown、YAML、CSS等文件解析

2. **知识图谱结构生成** (符合你要求的格式)
   ```json
   {
     "nodes": [
       { "id": "文件路径:节点名", "type": "节点类型", "name": "节点名称", "file": "所属文件" }
     ],
     "edges": [

     ]
   }
   ```

   - references (引用), exports (导出)

## 🚀 使用方法

### 方法一：VS Code 插件方式

1. **编译插件**
   ```bash
   npm run compile
   ```

2. **在VS Code中调试**
   - 按 F5 或选择 "运行和调试"
   - 会打开新的VS Code窗口（扩展开发宿主）

3. **使用插件命令**
   - 打开命令面板 (Ctrl+Shift+P)
   - 执行以下命令：
     - `GraphRAG: 构建知识图谱` - 解析整个项目
     - `GraphRAG: 查看知识图谱` - 可视化展示
     - `GraphRAG: 导出知识图谱` - 导出JSON文件
     - `GraphRAG: 语义搜索` - 搜索节点
     - `GraphRAG: 索引代码库` - 重新索引

### 方法二：直接调用API

```javascript
const { parseTsFile, parseVueFile } = require('./dist/parser-optimized');
const { KnowledgeGraph } = require('./dist/graph');

// 解析单个文件
const result = parseTsFile('./your-file.ts');
console.log('节点:', result.nodes);
console.log('边:', result.edges);

// 使用知识图谱管理器
const graph = new KnowledgeGraph();
graph.addNodes(result.nodes);
graph.addEdges(result.edges);

// 导出为你要求的格式
const exportData = {
  nodes: graph.getAllNodes(),
  edges: graph.getAllEdges()
};
```

## 🔧 配置选项

项目支持以下配置 (在package.json中定义)：

- `maxNodesPerFile`: 每个文件最大节点数 (默认: 100)
- `maxFileSizeKB`: 最大文件大小限制 (默认: 50KB)
- `includeTemplate`: 是否解析Vue模板 (默认: false)
